# R_time_series

R로 관측값을 두 구간으로 나누고, 좌우 평균 차이가 가장 큰 위치를 찾는 학습 프로젝트입니다. 추가 패키지는 필요하지 않습니다.

장기 목표는 **기존 고차원 시계열 분석 방법을 R로 구현하고 검증하며 R 패키지로 정리하는 역량**을 기르는 것입니다. 현재 코드는 그 출발점인 단변량 평균 차이 연습이며, CUSUM이나 Double CUSUM의 구현은 아닙니다. 단계별 계획은 [ROADMAP.md](ROADMAP.md)에 기록합니다.

## 실행 방법

`R_time_series.Rproj`를 RStudio에서 열고 콘솔에서 실행합니다.

```r
source("check_examples.R")
source("practice.R")
source("tests/test_find_split.R")
```

터미널에서는 **저장소 폴더에서** `Rscript --vanilla check_examples.R`처럼 실행합니다. 이전 세션의 `.RData`나 실행 기록은 필요하지 않습니다.

## 함수와 결과 해석

- `split_gaps(x)`는 후보 위치 `k`, 왼쪽 평균, 오른쪽 평균, `gap = 오른쪽 평균 - 왼쪽 평균`을 표로 반환합니다.
- `find_split(x)`는 `abs(gap)`이 가장 큰 위치를 반환합니다. `4`는 **4번째 관측값 다음에서 나눈다**는 뜻입니다.
- 양수 gap은 오른쪽 평균이 더 높고, 음수는 더 낮다는 뜻입니다.
- 모든 후보의 gap이 정확히 0이면 `NA_integer_`를 반환합니다. 동률이면 가장 앞의 위치를 택합니다.
- 기본값 `min_segment = 1`은 원래 연습 방식입니다. `min_segment = 2`로 양쪽에 최소 두 관측값을 요구할 수 있습니다.
- 길이 2 미만, 비숫자, 결측값, 무한대는 오류로 처리합니다. 결측값을 자동 삭제하면 시간 순서와 위치 해석이 달라질 수 있어 삭제하지 않습니다.

**이 함수는 탐색용 후보 선택이며 통계적 변화점 검정이 아닙니다.** 잡음만 있어도 최대 차이 위치가 나올 수 있습니다. 일정한 평균 주변에서 움직이는 예제도 후보를 반환합니다. `NA` 역시 통계적으로 '변화 없음'을 입증하지 않습니다. 짧은 끝 구간과 이상치에 민감하며 자기상관, 추세, 계절성을 따로 다루지 않습니다.
